# Planificador HGCS 2° Medio

Aplicación web para planificar los Objetivos de Aprendizaje (OA 1 a OA 25) de Historia, Geografía y Ciencias Sociales de 2° Medio (Chile).

## Qué hace

- Muestra los 25 OA ordenados en las 4 unidades del Programa de Estudio.
- Permite planificar clase a clase, por semana, por mes o por unidad.
- Incluye evaluación diagnóstica, formativa y sumativa, con rúbrica, escala, lista de cotejo o tabla de especificaciones.
- Propone habilidades (OAH), actitudes (OAA) y adecuaciones (DUA, TEA, TDAH, DEA y otras).
- Descarga la planificación como documento Word (.docx) con indicadores, objetivos de clase, actividades, adecuaciones y actitudes.

## Uso

Abre `index.html` en el navegador, o publícalo con GitHub Pages. No necesita servidor ni instalación.

## Nota

Los textos de los OA están adaptados de las Bases Curriculares 7° básico a 2° medio (Decreto 614/2013). Antes de usarlos en documentos oficiales, compáralos con la redacción de [curriculumnacional.cl](https://www.curriculumnacional.cl).
